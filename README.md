# Homebrew Tap — Ollama Usage Widget

Personal tap for [Ollama Usage Widget](https://github.com/AsharFatmi/ollama-usage-widget).

## Install

```bash
brew tap asharfatmi/tap
brew install --cask ollama-usage-widget
```

Or directly:

```bash
brew install --cask asharfatmi/tap/ollama-usage-widget
```

## Requirements

- macOS 14 (Sonoma) or newer
- Apple Silicon (arm64)

## Update

```bash
brew update && brew upgrade --cask ollama-usage-widget
```

## Uninstall

```bash
brew uninstall --cask ollama-usage-widget
```
